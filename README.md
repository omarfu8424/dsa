# dsa

## 目录结构

- `include/`：各数据结构模块的公共头文件和模板实现。
- `src/`：示例程序、库实现和按模块组织的源文件。
- `tests/`：CTest 测试。
- `resources/input.txt`：Huffman 示例输入。

## 构建与测试

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## BST 与 AVL 树高度实验

普通 BST 和 AVL 树分别提供独立的高度实验。BST 实验中，升序插入会退化成
高度为 `n - 1` 的链；AVL 树会在插入过程中旋转，因此仍保持对数级高度。

运行 BST 实验：

```bash
./build/BST_height_experiment
```

运行 AVL 实验：

```bash
./build/AVL_height_experiment
```

AVL 实验使用递推 `N(h) = N(h - 1) + N(h - 2) + 1` 得到高度上界。两个实验
都使用固定种子，输出随机插入的平均高度及其与 `ln(n)` 的比值，同时输出升序
插入和近似完全平衡插入的高度。

### 实验结果分析

在固定种子和 32 次随机采样下，实验结果如下（树高的根节点高度为 `0`）：

| `n` | BST 随机平均 | BST 升序 | BST 平衡 | AVL 随机平均 | AVL 升序 | AVL 平衡 |
|---:|---:|---:|---:|---:|---:|---:|
| 127 | 13.625 | 126 | 6 | 7.938 | 7 | 6 |
| 511 | 18.844 | 510 | 8 | 10.344 | 9 | 9 |
| 2047 | 23.875 | 2046 | 10 | 12.969 | 11 | 11 |

可以观察到：

- **最坏情况差异明显**：BST 在升序插入时退化为链，高度从 `O(log n)` 变为
  `n - 1`；AVL 会通过旋转保持平衡，升序插入的高度仅为 `7`、`9`、`11`。
- **随机数据下 AVL 更矮**：在三个规模上，AVL 的随机平均高度都低于 BST，
  说明局部旋转有效地消除了随机插入形成的偏斜。
- **平衡序列下两者接近**：这里的平衡插入顺序本身接近完全二叉树，因此 BST
  已经能得到高度 `log2(n)`；AVL 不需要额外旋转，结果也基本相同。
- **规模增长时的趋势**：BST 随机高度与 `ln(n)` 的比值从 `2.813` 增长到
  `3.132`，表明随机 BST 的高度确实随对数增长，但仍可能出现较大波动；
  AVL 的对应比值约为 `1.64` 到 `1.70`，且受平衡不变量约束，最坏情况仍为
  `O(log n)`。

因此，普通 BST 适合能够控制输入顺序、且希望结构简单的场景；当输入顺序不可控
或必须保证最坏情况性能时，应优先使用 AVL 等自平衡搜索树。
